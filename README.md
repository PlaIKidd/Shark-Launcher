# Shark Launcher — сайт для GitHub Pages

1. Создай публичный репозиторий, например `shark-launcher-site`.
2. Загрузи `index.html`, `style.css`, `script.js` в корень репозитория.
3. Открой Settings → Pages.
4. Выбери Deploy from a branch → `main` → `/ (root)` → Save.
5. Дождись публикации адреса сайта.

Перед публикацией замени ссылки-заглушки `href="#"` на реальные URL установщиков и страниц VirusTotal. Ссылки скачивания сейчас намеренно отключены. Проверь IP сервера и информацию о проекте.
